## 지표 (기획서 9절)
| 지표 | 목표 | 평가 데이터 |
| --- | --- | --- |
| 눈 감김 2초 이벤트 검출 재현율 | 90% 이상 | 자체 연기 영상 |
| 2클래스(정상 vs 졸음) 정확도 | 90% 이상 | AI Hub, 10초 창, 탑승자 분리 |
| 3클래스 macro F1 | 규칙 기반 대비 향상 | AI Hub, 10초 창, 탑승자 분리 |
| 졸음 점수 ROC-AUC | 규칙 점수 대비 향상 | 정상 대 졸음 창 |
| 오경보율 | 보고, 임계치 근거 | 정상·다른 이상행동·자체 영상 |
| 경고 지연 | 약 2초 | 눈 감김 시작 → 경고 |
| 실시간 처리 속도 | 15 FPS 이상 | 웹캠 데모 |
