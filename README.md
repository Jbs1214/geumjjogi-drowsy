# 졸음운전 감지 (geumjjogi-drowsy)

웹캠 영상에서 운전자의 눈 감김·하품·고개 숙임을 실시간으로 분석해 **정상 / 주의 / 졸음**을 판정하고 경고한다.

- 기간: 2026.10.26 ~ 2026.11.09 (2주), 팀 「금쪽같은 우리 사이」
- 개발 방식: 규칙 기반 판정 + 실시간 경고 데모(MVP)를 먼저 만들고, 시퀀스 분류기와 비교 실험으로 확장

## 현재 상태

**뼈대 단계.** 폴더 구조와 `sequence_model/`·`eval/`의 파일 뼈대만 있다.

- 뼈대 파일의 함수는 이름·입력 형태·설명만 있고, 실행하면 `NotImplementedError`를 낸다.
- `landmarks/`·`rule_based/`·`demo/`는 빈 폴더다 (`.gitkeep`).
- 시퀀스 분류기 모델은 아직 정하지 않았다 (논문 검토 후 결정).

## 처리 흐름

```
웹캠 입력 → Face Landmarker(17개 좌표) → 시간 정보 표(pandas)
→ 특징 계산(EAR·MAR·고개 각도·PERCLOS) → 졸음 점수(0~100)
→ 판정(정상 / 주의 / 졸음) → 경고음·Streamlit 화면
```

- 얼굴 랜드마크는 MediaPipe 사전학습 모델(Face Landmarker, Tasks API)로 뽑는다. 직접 학습하지 않는다.
- 판정은 규칙 기반(PERCLOS, 눈 감김 2초)이 기본이다. AI Hub 데이터로 학습한 시퀀스 분류기(10초 시간창)와 비교해 더 나으면 바꾼다.

## 폴더 구조와 담당

| 폴더 | 하는 일 | 담당 |
| --- | --- | --- |
| `landmarks/` | 랜드마크 17개 좌표 추출, 시간 정보 데이터프레임, EAR·MAR·고개 각도 계산 | 김민영 |
| `rule_based/` | PERCLOS·졸음 점수 기준 규칙 판정, 경고 로직 | 김민영 |
| `demo/` | Streamlit 실시간 데모 | 김민영 |
| `sequence_model/` | 라벨의 정상/주의/졸음 대응, 10초 시간창 구성, 시퀀스 분류기 학습 | 육주영 |
| `eval/` | 공통 평가 지표, 규칙 대 학습 비교표 | 육주영 |

팀장 장범수는 AI Hub 데이터 신청·다운로드·선별, 자체 검증 영상 촬영과 라벨링을 맡는다 (전용 코드 폴더 없음).
